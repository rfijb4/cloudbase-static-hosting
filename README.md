## 部署前要准备什么

主要准备四样东西：完成实名认证的腾讯云账号、构建好的静态文件目录、一个完成 ICP 备案的域名，以及本地的 Node.js 环境。域名不备案也能先用默认域名测试，但正式对外访问建议备案。

- 账号：腾讯云账号并完成实名认证。
- 构建产物：Hexo 生成 `public/`，Vite/React 生成 `dist/`。上传的是这个目录里的构建产物，源码目录不要传。
- 域名：自定义域名需要 ICP 备案。未备案域名在微信、QQ 内打不开，这是国内静态站最常见的「部署成功但访问不了」。
- 本地环境：Node.js 和 npm，用来装 CLI。

## 腾讯云部署静态网站完整步骤

第一次部署分五步：创建 CloudBase 环境、开通静态网站托管、安装并登录 CLI、上传构建产物、绑定域名开 HTTPS。顺利的话半小时内能走完，备案时间另算。

### 1. 创建 CloudBase 环境

登录腾讯云 CloudBase 控制台，新建环境，计费方式选按量计费。初始化通常一两分钟。完成后在环境总览页复制环境 ID，后面 CLI 要用。

### 2. 开通静态网站托管

在 CloudBase 控制台左侧菜单找到「静态网站托管」，点「开始使用」。首次开通需要几分钟初始化。开通后能看到文件管理、设置等入口。

### 3. 安装 CLI 并登录

bash
npm i -g @cloudbase/cli
tcb login


`tcb login` 会打开授权页面，扫码确认。终端访问不了外网时，需要先给 shell 设代理，否则会卡在授权超时。

### 4. 上传构建产物

进入构建产物目录再部署：

bash
cd dist
tcb hosting deploy -e 你的环境ID


Hexo 的产物目录是 `public`，换成对应路径。文件多的时候偶尔会上传失败，重跑一次即可。上传完成后，控制台会给一个 `*.tcloudbaseapp.com` 的默认域名，可以直接打开检查。

命令写法注意：2020 年前后的教程写的是 `tcb hosting:deploy`，新版 CLI 用空格分隔的 `tcb hosting deploy`。照着旧教程敲会报错。

### 5. 绑定自定义域名和 HTTPS

在静态网站托管的设置里添加自定义域名，按提示到 DNS 服务商添加解析记录。证书由平台自动签发，绑定成功后开启强制 HTTPS 跳转。域名如果还没备案，这一步会卡住，先去控制台提交备案。

## 部署后容易踩的坑

部署本身不复杂，麻烦多在一些细节上：旧命令、备案、传错目录、流量被刷。下面几个是常见的卡点。

### 旧教程的命令已经变了

2020 年左右的教程用 `tcb hosting:deploy`，新版 CLI 是 `tcb hosting deploy`。命令不认，先检查版本和写法。

### 域名没备案，微信里打不开

静态站部署成功，浏览器用默认域名也能访问，但绑定的自定义域名如果没备案，在微信、QQ 内会被拦。备案要时间，别等上线当天才提交。

### 传错目录，首页 404

CLI 上传的是你当前所在目录。在项目根目录直接执行，可能把源码传上去，访问自然 404。先 `cd dist` 或 `cd public`，确认目录里是 `index.html` 和静态资源。

### CDN 流量被刷

静态托管底层走 CDN，流量按量计费。COS+CDN 方案可以在 CDN 控制台设置 Referer 白名单、IP 访问限频、下行限速和用量封顶；一套偏保守的起点是存储桶设为私有读写、单 IP 10QPS、下行 1024KB/s、5 分钟流量超过 2GB 或当天累计 10GB 时封顶。具体阈值按自己站点流量调整。CloudBase 静态托管用户至少养成看用量和账单的习惯。

### 更新后看到旧页面

COS+CDN 方案上传新文件后，CDN 缓存不会自动全刷新，需要在 CDN 控制台提交刷新，否则用户看到的还是旧页面。如果用 CI 自动上传，把刷新 CDN 缓存的步骤放在流水线最后。

## 常见问题

**腾讯云部署静态网站要买服务器吗？**

不用。CloudBase 静态网站托管和 COS+CDN 都不需要 CVM，静态文件放在托管服务或对象存储里，前面走 CDN。

**免费额度够个人博客用吗？**

多数个人博客够。1GB 存储能放不少 HTML、CSS 和压缩后的图片；每月 5GB 流量大约对应每月一万次页面访问（按每页 500KB 估算）。图片多、访问量大的站点会超，超出部分按量计费。

**自定义域名一定要备案吗？**

在国内访问需要 ICP 备案。未备案域名无法在微信、QQ 内打开。腾讯云控制台提供备案入口，备案期间可以先用默认域名测试。

**支持 HTTPS 吗？**

支持。绑定域名后自动签发证书，也可以开启强制 HTTPS 跳转，证书续期由平台处理。

**能部署 Vue、React、Hexo 吗？**

能。先用框架命令构建，再把 `dist` 或 `public` 目录上传。静态托管只存放构建后的文件，构建要在本地或 CI 里完成。

**部署一次要多久？**

环境初始化几分钟，上传取决于文件数量。第一次从开通到域名访问，顺利的话半小时左右；备案时间另算。

**CloudBase 静态托管和 COS 静态网站有什么区别？**

CloudBase 把上传、CDN、HTTPS、域名绑定封装在一个控制台里，适合不想逐项配置的人；COS+CDN 更底层，缓存策略、防盗刷、权限控制的可调项更多，适合已有 COS 桶或需要精细控制的场景。

**默认域名是什么？**

控制台会分配一个 `*.tcloudbaseapp.com` 的域名，可以直接访问和测试。正式对外建议绑定自己的域名。
